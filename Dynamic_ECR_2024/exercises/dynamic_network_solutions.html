1 Dynamic Networks Workshop

This document contains solutions for the workshop on dynamic networks held at the Goethe University Frankfurt, Germany, on 2024-10-23. Your solutions may vary slightly when you simulated data yourself.

1.1 Preparation

1.1.1 Load all packages

1.2 Simulation Code

This code shows how data were generated. You can skip this part.

Show the code 
n_id <- 75
n_tp <- 80
n_beep <- 4
n_days <-  n_tp/n_beep

# Simulate the data
sim_obj <- mlVAR::mlVARsim(
  nPerson = n_id,
  nNode = 6,
  nTime = n_tp,
  lag = 1
)

# Load the data
df_data <- sim_obj$Data

# Add day and beep variable per person, and 4 beeps per day
df_data$beep <- rep(rep(rep(1:n_beep, each = 1), n_days), n_id)
df_data$day <- rep(rep(1:n_days, each = n_beep), n_id)

# Rename ID to id
df_data$id <- df_data$ID

# Save the data

1.5 Exercise 3: Obtain and interpret individual networks

1.5.1 Task:

  • Obtain the individual temporal networks for individuals 1 and 2.
  • How different are they?

Tip 1: Check out the mlVAR::getNet() function.
Tip 2: Use the qgraph() function to plot the networks.

Show the code 
# Get the individual networks
net1 <- mlVAR::getNet(mlvar_fit, 
                      subject = 1,
                      type = "temporal")

net2 <- mlVAR::getNet(mlvar_fit,
                      subject = 2,
                      type = "temporal")

# Plot net1 and net2 in one plot
par(mfrow = c(1, 2))
qgraph(net1,
     theme = "colorblind",
     layout = "circle",
     edge.labels = TRUE,
     title = "Individual 1")
qgraph(net2,
     theme = "colorblind",
     layout = "circle",
     edge.labels = TRUE, 
     title = "Individual 2")
Show the code 
# Reset the plot layout
par(mfrow = c(1, 1))

## Exercise 3: Obtain and interpret individual networks

### Task:

-   Obtain the individual temporal networks for individuals 1 and 2.
-   How different are they?

**Tip 1**: Check out the `mlVAR::getNet()` function.\
**Tip 2**: Use the `qgraph()` function to plot the networks.

```{r}
# Get the individual networks
net1 <- mlVAR::getNet(mlvar_fit, 
                      subject = 1,
                      type = "temporal")

net2 <- mlVAR::getNet(mlvar_fit,
                      subject = 2,
                      type = "temporal")

# Plot net1 and net2 in one plot
par(mfrow = c(1, 2))
qgraph(net1,
     theme = "colorblind",
     layout = "circle",
     edge.labels = TRUE,
     title = "Individual 1")
qgraph(net2,
     theme = "colorblind",
     layout = "circle",
     edge.labels = TRUE, 
     title = "Individual 2")

# Reset the plot layout
par(mfrow = c(1, 1))
```

```{r, message=FALSE}
if(!require("gimme")) install.packages("gimme")
```
